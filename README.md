# 🤫 ㅁㅇㅅ (몰래 읽는 수다방)

디스코드 서버 대화를 업무 화면처럼 보이게 읽고 쓰는 웹사이트예요! 스프레드시트, 메모장, 노션, Word 모양으로 바꿔 쓸 수 있고, 보스키 한 번이면 진짜 업무 화면으로 바뀌어요. ㅁㅇㅅ 봇이 들어가 있는 서버에서만 쓸 수 있어요.

👉 **https://docs.teamsheet-note.com**

처음 들어가면 디스코드 계정을 연결하고, 이 사이트에서만 쓸 비밀번호를 정해요. 그다음부터는 비밀번호만 넣으면 열려요. 휴대폰에서는 계정 메뉴의 `앱으로 설치`로 홈 화면에 앱처럼 둘 수 있어요.

<br>

## 기능

### 🔐 계정과 잠금

| 기능 | 설명 | 어디서 |
| --- | --- | --- |
| 계정 연결 | 디스코드로 한 번 연결하고, 이후에는 비밀번호로 열기 | 처음 화면 |
| 자동 잠금 | 아무것도 안 하면 잠김 (5분 ~ 8시간, 기본 30분) | 설정 › 잠금 |
| 로그인 유지 | 30일 동안 잠그지 않기 (내 기기에서만 켜기) | 잠금 화면 |
| 여러 계정 | 한 브라우저에 5개까지, 로그아웃 없이 바꾸기 | 계정 메뉴 |
| 비밀번호 분실 | 디스코드로 다시 연결해서 새로 정하기 | 잠금 화면 |

### 💬 대화

| 기능 | 설명 | 어디서 |
| --- | --- | --- |
| 읽기, 보내기 | 채널, 스레드, 포럼 글을 실시간으로 | 채팅방 |
| 답장, 반응 | 메시지를 누르면 나오는 단추 | 메시지 |
| 고치기, 지우기 | 여기서 보낸 내 글만 (디스코드 앱에서 쓴 글은 앱에서) | 메시지 |
| 사진, 파일 | `＋` 단추, 붙여넣기, 끌어다 놓기. 큰 사진은 알아서 줄여요 | 입력칸 |
| 이모지, 스티커 | 서버 이모지와 기본 이모지 전부, 니트로 이모지는 니트로 확인 후 | 입력칸 |
| 멘션 자동완성 | `@` 사람, `#` 채널 | 입력칸 |
| 찾기와 서랍 | 받아 둔 메시지 찾기, 고정 메시지, 사진, 파일, 멤버 | 채팅방 머리 단추 |
| 맨 아래로 | 위로 한참 올리면 오른쪽 아래에 단추 (새 메시지 수 함께) | 채팅방 |
| 포럼 | 글 목록, 새 글, 제목과 태그 고치기 | 포럼 채널 |
| 음성 채널 | 누가 들어가 있는지 보기, `디스코드에서 참여` | 음성 채널 |

### 🎭 테마

| 테마 | 모양 |
| --- | --- |
| 기본, 다크 | 메신저 말풍선 |
| 스프레드시트 | 메시지 한 줄이 시트 한 행, 채널은 아래 시트 탭 |
| 메모장 | `시각 이름: 내용` 기록 |
| 노션 | 데이터베이스 표 (작성 일시, 작성자, 내용) |
| Word | 여러 사람이 같이 쓰는 문서 |

- 탭 제목, 탭 아이콘, 왼쪽 목록, 잠금 화면까지 테마에 맞춰 바뀌어요.
- Word 문서 제목과 노션 페이지 제목은 눌러서 바로 고칠 수 있어요 (서버, 채널 이름은 그대로).

### 🙈 위장 화면

| 기능 | 설명 | 어디서 |
| --- | --- | --- |
| 보스키 | 아무 화면에서나 누르면 업무 화면으로, 한 번 더 누르면 돌아오기 (기본 `Esc` 두 번) | 설정 › 위장 화면 |
| 휴대폰 | 화면 왼쪽 아래 모서리 누르기 | 아무 화면 |
| 보여 줄 화면 | 예시 4가지, 내 파일 (.xlsx .csv .txt .md .docx), 내 화면 사진, 다른 사이트 | 설정 › 위장 화면 |
| 더 숨기기 | 자동 위장, 위장할 때 전체 화면, 돌아올 때 잠그기 | 설정 › 위장 화면 |

## 참고

- 설정은 기기마다 따로예요. 회사 컴퓨터와 휴대폰을 다르게 정할 수 있어요. 위장 화면에 올린 파일, 고정, 순서, 숨긴 목록, 고친 문서 제목은 모든 기기에서 같아요.
- 사진, 동영상, 파일도 이 사이트를 거쳐서 받아요. 회사 망 기록에 디스코드 주소가 남지 않아요.
- 받아 둔 메시지는 90일이 지나면 여기서만 지워져요. 디스코드 원본은 그대로고, 위로 올리면 다시 불러와요.
- 음성 채널 참여, 다른 봇의 버튼과 투표, 다른 봇의 `/` 명령은 디스코드 앱에서 해야 해요.
- 비공개 채널은 서버 관리자가 그 채널에 ㅁㅇㅅ 봇을 추가해야 보여요.
- 더 자세한 사용법은 사이트의 계정 메뉴 › `사용 방법`에서 다시 볼 수 있어요.
